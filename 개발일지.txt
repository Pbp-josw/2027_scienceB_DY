# [개발일지] 중학교 과학 인터랙티브 온라인 학습지 & 마이크로 LMS 플랫폼

- 프로젝트명: 대영중학교 맞춤형 과학 디지털 학습지 & 마이크로 LMS 플랫폼
- 작성일시: 2026-11-15 (최신 업데이트: 실제 종이 학습지 디자인 규격 반영)
- 대상: 중학교 과학 (학년별 약 200명 규모 / 학급당 25~30명)
- 레퍼런스: '움직이는 통합과학 수업 · 꿈틀' (https://pang99x-hub.github.io/science-slides/index.html)
- 실제 학습지 원본 분석: 대영중 3학년 과학 학습지 3종 (복사 평형, 화학 반응 에너지, 일정 성분비 법칙)

================================================================================
1. 프로젝트 기획 배경 및 문제의식
================================================================================
(1) 기존 수업 방식의 한계
  - 전통적인 종이 학습지 배부 + 교사용 PPT 화면 제시 위주 수업.
  - 가끔 시뮬레이션을 개별 배포했으나 분절된 느낌이며, 수업 흐름 장악과 학생 반응 수집에 한계.
  - 200명 규모의 종이 학습지 검사, 보관, 누적 포트폴리오 관리의 높은 피로도.

(2) 지향하는 핵심 목표
  - [통합성] 수업 슬라이드 + 학생 인터랙티브 활동 + 온라인 학습지가 하나로 유기적 연결.
  - [수업 주도권] 전자칠판 중심의 교사 화면 통제(강제 동기화)와 학생 개별 자율 탐구 모드의 유연한 전환.
  - [수업 자원화] 학생들의 실시간 응답/측정값/생각/미디어가 수업의 핵심 소재(그래프, 갤러리, 토론 거리)로 즉각 활용.
  - [누적 포트폴리오] 학생별·차시별 학습 활동이 자동으로 누적되어 과정중심 평가 및 생기부 근거 자료화.
  - [A4 학습지 인쇄/PDF 지원] 디지털 환경뿐 아니라 시험 복습을 위해 기존 종이 학습지 양식과 100% 동일한 A4 인쇄/PDF 뷰 지원.
  - [자기주도 마이크로 LMS] 수업 시간 외에도 학생이 언제든 접속해 학습 진단, 오답 복습, 동료와 질의응답 가능한 플랫폼.
  - [컴포넌트 객체화] 수업 기능을 레고 블록처럼 태그 단위로 조합하여 신규 차시 제작 시간을 획기적으로 단축.

2. 실제 종이 학습지 디자인 표준 규격 (A4 Worksheet Design System)
================================================================================
대영중학교 과학과 실제 수업 학습지의 시각 문법을 100% 완벽하게 디지털로 계승:

(1) 헤더 영역 (Header Blueprint)
  - 좌측 상단: 과목 전용 원형 흑백 인장 (化學, 物理, 生命科學, 地球科學)
  - 메인 타이틀: 나눔스퀘어 ExtraBold(800) 묵직한 고딕 (예: '복사 평형을 이루는 지구')
  - 상단 메타: `3학년 ( )반 ( )번 이름: _____` | `교과서 OO - OOp ■■■`
  - 우측 단원 표기: 2단 분할 박스 (`대단원: ...` / `중단원: ...`) 또는 `뒷면` 표기.
  - 상하 구분선: 굵은 3선 또는 2선 라인아트 마감.

(2) 학습 목표 바 (Target Objective Bar)
  - 좌측 뱃지: 검은색 사각 반전 뱃지 `[ 학습 목표 ]` 또는 `[ 데이터 ]`
  - 우측 목표문: 명확한 성취기준 행동 동사 ("~를 설명할 수 있다.")

(3) 6대 핵심 분류 뱃지 시스템 (Category Badge System)
  모든 본문 모듈은 검은색 바탕 + 흰색 볼드 글씨의 라운드 뱃지로 성격을 명확히 규정:
  - `[ 개념 | ... ]` : 정규 교육과정 필수 개념 (예: 개념 | 복사 평형, 개념 | 화학 반응과 에너지)
  - `[ 탐구 | ... ]` : 실험, 모형 해석, 데이터 수집 (예: 탐구 | 일정 성분비 법칙_모형 해석)
  - `[ 심화 | ... ]` : 고등학교 화학I 연계, 한계 반응물, 반응 전/중/후 양적 관계 해석
  - `[ 참고 | ... ]` : Universe, 시공간, 흑체, 열과 온도, 관성 등 STEAM 융합 사고 확장
  - `[ 해석 | ... ]` : 데이터 해석 및 결론 도출 (데이터 해석 결과 및 결론 표)
  - `[ 복습 | ... ]` : 이전 차시 선수 학습 회상 (순물질, 혼합물, 물질의 분류)

(4) 2단 다단 그리드 & 모듈러 카드 (2-Column Modular Grid)
  - A4 규격(210mm × 297mm) 좌우 2열 분할 레이아웃 (`grid-template-columns: 1fr 1fr; gap: 12px;`).
  - 모듈 박스: 1.5px 단단한 검은색 외곽선 (`border: 1.5px solid #0F0F0F;`).
  - 정형화된 데이터/비교 테이블: `정적 평형 vs 동적 평형`, `발열 vs 흡열`, `반응 전/중/후 3단 표`.
  - 인포그래픽 프레임: 실험 장치 모식도, 입자 모형 카드 하단에 캡션 라벨 박스 배치.

(5) 인터랙티브 빈칸 및 서술형 라인
  - 빈칸 괄호: 종이에서는 `(      )`, 웹 화면에서는 탭하면 정답이 노출되는 인터랙티브 블라인드.
  - 서술형 밑줄: `________________________________________________` 정갈한 밑줄 라인 지원.

4. 시스템 아키텍처 및 11대 기능 요약
================================================================================
[기능 1] 교사-학생 실시간 화면 동기화 (Teacher-Led Synchronization)
[기능 2] 200명 규모 명렬표 기반 제로 가입 (`[코드4자리] + [학번] + [이름]`)

[기능 9] 동료 학습 게시판 (학생 출제 퀴즈 배틀 + 멘토링 Q&A)
[기능 10] 교사용 관리 대시보드 (반별 탭 + 미완성자 필터 + 학기말 엑셀 다운로드)
[기능 11] A4 종이 학습지 뷰 (선생님의 실제 학습지 서식 100% 동일 인쇄/PDF 뷰)

5. 메인 허브 인터페이스 개편 및 인라인 편집 아키텍처 (2026-11-15 완료)
================================================================================
(1) 타이틀 단일화 및 네오브루탈리즘 타이포그래피 정립
  - 기존 렌즈 복제(clone) 요소 충돌로 발생하던 타이틀 중복 렌더링 현상 완전 제거.
  - 스크린샷 표준 규격 반영: 순백색 텍스트(#FFFFFF) + 2.5px 묵직한 블랙 외곽선(#0B0B0C) + 5px 3D 솔리드 블랙 하드 섀도우 단일 요소 적용.
(2) 차시(Lesson Rows) 플렉스 레이아웃 정돈
  - 체크 서클(24px 원형, 완료 시 에메랄드 그린 + 검은 V 표시)
  - 차시 번호: 검은색 모서리가 둥근 사각 배지 (`1차시`, `2차시`)
  - 수업 제목, 탐구 질문(연회색 하이라이트 박스), 교과서 쪽수 및 슬라이드 수 플렉스 정렬
  - 우측 액션 버튼: 시원한 내부 패딩과 3D 섀도우 마감 (`수업 참여`, `A4 학습지`)
(3) 웹 표준(HTML+CSS+JS) 기반 교사용 인라인 즉석 편집(In-place Edit) 시스템
  - 별도 수정 버튼 없이, 교사 모드 진입 후 단원명/수업명/핵심질문/쪽수를 클릭하면 즉시 키보드로 입력 가능(`contenteditable="true"`).
  - 엔터키 입력 시 자동 완료 및 blur 이벤트 발생 시 `localStorage` 자동 영구 저장 연동.
  - 단원별 `+ 차시 추가` 버튼을 지원하여 모듈 확장이 웹 브라우저 자체에서 무한 가능하도록 구현.
